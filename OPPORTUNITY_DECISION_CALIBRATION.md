# Module 2 Opportunity-Decision Calibration

## Open only after the original decision is locked

Do not use this page to write
`independent_opportunity_decision.md`. First complete that record, close it,
create `independent_opportunity_decision.sha256`, and confirm that the hash
matches. This separation protects the evidence of what you could decide before
seeing the calibration guidance.

There is no answer key that requires one positive label. `SELECT`,
`DISCOVER FURTHER`, and `DISCARD` can each be defensible when the evidence,
boundaries, and smallest next step support the choice.

The decision is `NOT YET` when it:

- treats a stated assumption as measured fact;
- ignores the uninspected existing-tool capability;
- uses a numerical score to override a hard stop;
- claims artificial intelligence (AI) is required before the problem and
  baseline are known;
- omits reversibility, failure consequence, or a smallest next evidence step;
- gives Candidate A and Candidate B identical reasoning despite their
  different evidence.

Compare those points with the locked record. Do not edit the original. If this
calibration exposes a weakness, create
`independent_opportunity_reassessment.md` and record:

1. the original Secure Hash Algorithm 256-bit (SHA-256) value;
2. the specific weakness found;
3. the corrected reasoning;
4. whether the label changes and why; and
5. the smallest next evidence step.

A thoughtful reassessment does not erase a first-attempt mistake. Preserving
both records is the learning evidence.
