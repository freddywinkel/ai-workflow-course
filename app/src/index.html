Install Course 1 on this device

An installed application opens from its own icon and keeps the core reading material available offline.

Desktop computer or Android device

  1. If the Install application button appears below, select it and confirm.
  2. If that button is absent, open your browser menu and choose Install app or Add to Home screen.
  3. Open the new course icon once while online.

iPhone or iPad

  1. Open this page in Safari, Apple’s web browser.
  2. Tap Safari’s Share button.
  3. Choose Add to Home Screen.
  4. Turn on Open as Web App when that option appears.
  5. Tap Add, then open the new icon once while online.

The core reading material is then available offline. Progress remains local to this device.
